# 📸 Galeria de Fotos – Unsplash API

## 📖 Descrição do Projeto

Esta aplicação consiste em uma **galeria de fotos dinâmica**, desenvolvida para carregar imagens **em tempo real** a partir da **API do Unsplash**, utilizando um **mecanismo de pesquisa**. O usuário pode buscar por palavras-chave e visualizar instantaneamente fotos relacionadas, de forma simples e intuitiva.

O projeto foi criado com foco em praticar o consumo de APIs externas, manipulação do DOM e uso de JavaScript para criar interfaces interativas.

---

## 🚀 Funcionalidades

- 🔍 Pesquisa de imagens por palavra-chave  
- 🌐 Consumo da API pública do Unsplash  
- 🖼️ Carregamento dinâmico de imagens em tempo real  
- 📱 Interface responsiva
- ⚡ Atualização da galeria sem recarregar a página  

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** – Estrutura da aplicação  
- **CSS3** – Estilização e responsividade  
- **JavaScript** – Lógica da aplicação, consumo da API e manipulação do DOM  
- **Unsplash API** – Fonte das imagens  

---

## 🔗 API Utilizada

- **Unsplash API**  
  Permite acessar um vasto banco de imagens de alta qualidade de forma gratuita.

📌 Para utilizar a API, é necessário:
1. Criar uma conta em: https://unsplash.com/developers  
2. Gerar uma **Access Key**  
3. Inserir a chave no código JavaScript para autenticação das requisições
